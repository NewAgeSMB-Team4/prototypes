    ELDT theory

    Curriculum
    Students in theory
    Final theory test
    auto-graded in the student app · federal minimum 80%
    Section Required topics Questions in bank Section quiz Avg score
    Section quizzes are drawn from the question bank for that section and can be retaken by the student as often as they like; those scores are practice only. The final theory test covers every section, needs 80% to pass, and its attempts are limited by the program and recorded on the student's file.
    Theory progress by student
    Student Started Units completed Final theory test Completed on Theory status

    Each licence type has its own FMCSA theory curriculum (49 CFR Part 380): Class A Appendix A, Class B Appendix B, Passenger Appendix D, School bus Appendix E, Hazmat Appendix F. Schools may add units but must cover every required topic.

      Settings

      Enrollment agreement template
      School-wide default text. Every program uses it unless the program has its own edited text (Training › Programs › Edit agreement text). Includes the cancellation and refund policy as a section. Students e-sign it in the app.
      v3 · Aug 1, 2026 · Robert Mitchell
      Saving creates v4; existing signed agreements keep the version they were signed on.
      Fees and charges
      School-wide amounts for retests, retakes and missed sessions. They are quoted to the student before they commit and added to their account when the office applies them. Program and enrollment fees are set on each program.
      Charge Amount When it applies
      Charges already added to a student's account keep the amount charged at the time.
      Session lengths
      Default length for each session type. FMCSA sets total hours, not session length, so these are the school's own policy. The office can shorten or lengthen an individual booking, and hours are credited from the actual start and end times recorded by the instructor.
      Session type Default length Notes
      New bookings use these; sessions already scheduled keep their times.
      Required documents by program
      Tick the documents each program asks for at enrollment. The enrollment form and the student's Documents tab follow this list, so a Hazmat student is never asked for a drug test and a P endorsement student is asked for their existing CDL.
      Document type Expiry tracked Class A Class B B → A upgrade Passenger (P) School bus (S) Hazmat
      Standard types cannot be removed; school-added ones can.
